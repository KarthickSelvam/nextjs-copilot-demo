Todo App

This is a simple Todo App built with NextJS. The home page displays a list of todos fetched from an API.

## How to run the app

1. Clone the repository:
   ```
   git clone https://github.com/KarthickSelvam/nextjs-copilot-demo.git
   ```
2. Navigate to the project directory:
   ```
   cd nextjs-copilot-demo
   ```
3. Install the dependencies:
   ```
   npm install
   ```
4. Run the development server:
   ```
   npm run dev
   ```
5. Open your browser and go to `http://localhost:3000` to see the app in action.
